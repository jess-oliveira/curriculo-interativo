# Currículo Interativo

Projeto prático de desenvolvimento web que transforma um currículo profissional tradicional em uma aplicação interativa e responsiva.

O objetivo é aplicar e demonstrar conhecimentos adquiridos na formação em Análise e Desenvolvimento de Sistemas (ADS), em cursos complementares e nos estudos de Quality Assurance (QA).

## 🎯 Objetivo

Desenvolver uma aplicação web que facilite a consulta de informações profissionais, permitindo que recrutadores explorem habilidades e visualizem evidências práticas relacionadas a elas.

O projeto também tem como finalidade proporcionar uma experiência de desenvolvimento de ponta a ponta, envolvendo análise de requisitos, modelagem, programação e testes de software.

## ⚙️ Funcionalidades previstas

- Apresentação de informações pessoais e profissionais.
- Navegação por seções em uma única página.
- Organização de habilidades por categorias.
- Filtros com seleção simultânea de habilidades e atualização imediata dos resultados.
- Exibição de evidências práticas relacionadas às habilidades, quando disponíveis.
- Informações sobre formação e cursos relacionados.
- Links para GitHub, LinkedIn e WhatsApp.

## 🛠️ Tecnologias e ferramentas

- **Desenvolvimento:** HTML, CSS e JavaScript.
- **Automação de testes:** Cypress.
- **Versionamento:** Git e GitHub.
- **Modelagem e documentação:** Draw.io (diagrams.net).

## 📋 Documentação e qualidade

O desenvolvimento será acompanhado por documentação técnica, incluindo análise de requisitos, registro de decisões, modelagem do sistema e documentação de testes.

Também serão aplicados testes manuais e automatizados para verificar o funcionamento, a usabilidade, a navegação e a responsividade da aplicação.

## 📚 Propósito e aprendizados

Mais do que desenvolver um currículo web, este projeto busca consolidar conhecimentos acadêmicos e praticar habilidades de análise, desenvolvimento e qualidade de software.

A aplicação também servirá como portfólio técnico, permitindo demonstrar o processo de construção, as decisões tomadas e os resultados alcançados.
